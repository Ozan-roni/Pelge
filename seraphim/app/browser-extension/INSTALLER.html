Votre navigateur, votre contrôle.

Compagnon 0.14.0 pour Chrome et Edge.

  1. Ouvrez chrome://extensions ou edge://extensions.
  2. Activez le mode développeur, puis choisissez « Charger l’extension non empaquetée ».
  3. Sélectionnez le dossier browser-extension situé à côté de Seraphim.exe.
  4. Si le compagnon est déjà installé, cliquez simplement sur « Recharger », puis rechargez les onglets sociaux ouverts.

Préparez les règles dans Seraphim > Applications. Elles s’appliquent seulement pendant une session active.
